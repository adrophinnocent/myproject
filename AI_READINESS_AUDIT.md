## 3. Specification evaluations

### MCP discovery (SEP-2127 / AI Catalog)

MCP Server Cards are an optional, Extensions Track discovery format for **remote MCP servers**. They describe an actual Streamable HTTP endpoint, protocol versions and identity; the spec explicitly says servers without a card work normally and that cards must not advertise fake primitives. The site has **no MCP server** — `POST /ai-assistant/chat` is a normal Laravel form endpoint with a proprietary JSON response, not JSON-RPC 2.0 and not MCP. Therefore no `/.well-known/ai-catalog.json`, no `server-card` and no `/.well-known/mcp.json` were published. A test asserts these paths stay 404.

### DNS-AID (`draft-mozleywilliams-dnsop-dnsaid-01`)

DNS-AID publishes agent discovery data as DNS `SVCB`/`HTTPS` records under `_agents.<domain>`, signed with DNSSEC, optionally with DANE TLSA and DCV TXT records. It is an Internet-Draft (not an RFC), and it can only be deployed in the DNS zone at the registrar/DNS provider. There is no public agent endpoint on this domain to point at, and adding unsigned or placeholder records would be actively harmful. No DNS changes were made. If a real agent endpoint is launched later, the DNS host can add records such as `_index._agents.twinasafaris.com. IN SVCB ...` with DNSSEC at that time.

### Agent Skills (agentskills.io specification)

A skill is a directory containing `SKILL.md` with YAML frontmatter: `name` (1–64 lowercase alphanumeric/hyphen, must match the directory), `description` (1–1024 chars), optional `license`, `compatibility`, `metadata` and `allowed-tools`. The published file satisfies the required fields and stays well under the recommended 500 lines. The spec defines no web-wide discovery URI, so the skill is linked from `llms.txt` rather than invented at a `.well-known` path.

### llms.txt convention

Follows the llmstxt.org convention: H1 project name, blockquote summary, then H2 sections of `- [title](url): description` bullets. Markdown siblings are advertised explicitly because the convention itself has no formal machine-readable field for alternates.

## 5. Operational notes

- AI crawler policy is data, not code: edit `config/ai.crawlers` (or set it via deployment config) and run `php artisan config:cache` to add/remove a crawler. Removing a crawler from that list means it falls back to the wildcard group — it is **not** blocked.
- Feature flags `AI_MARKDOWN_ENABLED`, `AI_MARKDOWN_NEGOTIATION_ENABLED` and `AI_LINK_HEADERS_ENABLED` default to `true` in `config/ai.php`.
- All Markdown endpoints return `Cache-Control: public, max-age=3600` and a canonical `Link` header; they are not in the sitemap and are not separate indexable pages.
- The Markdown converter uses only `dom`/`libxml` (already enabled). No new dependency, no JS, no external service.
